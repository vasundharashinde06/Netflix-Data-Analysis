# Netflix Data Analysis

## 📌 Project Overview
This project analyzes the Netflix Movies and TV Shows dataset using Python. The project includes data cleaning, exploratory data analysis (EDA), and visualizations to discover trends in Netflix content.

## 🛠️ Technologies Used
- Python
- Pandas
- Matplotlib

## 📊 Analysis Performed
- Top 10 content-producing countries
- Movie vs TV Show distribution
- Most common genres
- Content added over the years
- Ratings distribution
